PROJECT / 003 — PORTFOLIO

RYO PORTFOLIO.

自分の自己紹介、学んでいる技術、制作した作品をひとつのWebサイトにまとめたポートフォリオです。見る人が作品をスムーズに確認できる構成を目指しました。

01 / FEATURES

実装した機能.

01

レスポンシブ対応

PCやスマートフォンでも見やすいレイアウトになるよう、画面幅に合わせて表示を変えています。

02

作品フィルター

作品カテゴリを選択すると、一覧の表示を絞り込めます。

03

テーマ切り替え

ライトテーマとダークテーマを切り替えられるボタンを実装しています。

02 / TECHNOLOGY

使用技術.

HTML / CSS

サイトの構造とデザイン、レスポンシブレイアウトを作成しました。

JavaScript

作品フィルター、スマートフォンメニュー、テーマ切り替え、スクロール表示を実装しました。
